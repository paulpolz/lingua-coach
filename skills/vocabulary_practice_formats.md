# Vocabulary Practice Formats

Supporting reference for `exercise_tutor.md`. Use at week end, before weekly test. Swap in that week's target words. Both formats built for partner practice; solo alternatives noted.

## Format A — Word Web / Scenario / Manifesto

Personal and narrative lean.

0. **Word bank** — 6–10 words, one-line gloss (2 min)
1. **Word web relay** — chain connected words from bank; name the link (2–3 min × 2)
2. **Describe, don't say it** — define without saying the word; partner guesses (5 rounds each)
3. **Scenario + verdict** — short profile using target words; discuss and deliver a verdict
4. **Guilty as charged** — "I'm a bit like [name] because I also tend to ___, especially when ___."
5. **Hot takes** — bold statements; react using bank words
6. **The manifesto** — My rule / My reason / My example (≥1 bank word each)
7. **What I'm keeping** — 3 words you'll actually reuse and why

*Solo:* narrate chains, record describe-and-guess, write scenario and manifesto.

## Format B — Warmer / Myth Busters / Steal the Opinion

Debate and judgment lean; good for argument-heavy goals.

0. **Related vocabulary** — bank in 3–4 columns
1. **Warmer** — 3–4 options; pick what's true for you now, one sentence why
2. **Vocabulary revision** — partner says word; you have 10s for one true personal sentence (swap roles)
3. **Diagnose and disagree** — case studies + bad advice; explain why and write better advice (≥2 target words)
4. **Myth busters** — Myth / True / Depends vote, then defend
5. **If this had a rating** — rate strategies 1–5 independently; compare disagreements
6. **Steal the opinion** — argue assigned position 2 min; reveal real view
7. **One thing I'm stealing** — one idea to try; one blocker to "eventually"

## Cadence

Alternate A and B week to week, or pick by content (A → personal/narrative weeks, B → opinion/debate weeks).
